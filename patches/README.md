# TEB v4.1.2 local modifications

`teb_v4.1.2_local_modifications.patch` is the exact `git diff` of the TEB
working tree used for every TEB run in the paper, relative to the upstream
commit `b685f5f322d2ec55e4d9f8d72716d32f0b5200e9` (tag `4.1.2`,
<https://github.com/TEB-model/teb>; software archive
<https://doi.org/10.5281/zenodo.5775962>).

## What the patch changes

1. `src/driver/driver.F90`: the `namelist` statements are moved after the
   variable declarations so that the driver compiles with gfortran 13
   (a build fix; no change to the computation).
2. `src/teb/avg_urban_fluxes.F90`, `src/teb/spll_modi_avg_urban_fluxes.f90`,
   `src/teb/teb_garden.F90`: two extra arguments (wind modulus, town
   Richardson number) are threaded into the flux-averaging routine and three
   optional canyon-air heat-source terms are added. These terms belong to an
   earlier, separate line of work and are **dormant**: they are activated only
   when the environment variable `TEB_DH_CLOSURE` is set to `1`, `2` or `3`
   (and `TEB_DH_DIAG=1` writes a diagnostic file). With the variables unset the
   scheme computes exactly as upstream TEB v4.1.2.

Every TEB run used in the paper (baseline, albedo-constrained campaign,
spin-up campaign, material-perturbation probe) was made with these variables
**unset**. This is verified in `results/review5_run_provenance.json`
(generated by `analysis/revalidation_2026-08/scripts/review5_run_provenance.py`):
a fresh run of the patched build reproduces the archived baseline output
`external/teb_runs/<SITE>/output/LWU_base.txt` bit for bit. The small files
`closure2_coefs.txt` / `closure3_coef.txt` that sit in the archived run folders
are read only inside the dormant branches and are not shipped.

## Rebuilding TEB

```
git clone https://github.com/TEB-model/teb external/teb
cd external/teb && git checkout 4.1.2
git apply ../../patches/teb_v4.1.2_local_modifications.patch
mkdir build && cd build && cmake -DCMAKE_BUILD_TYPE=Release .. && cmake --build . -j8
```

The driver binary is then `external/teb/build/driver`, which is where
`analysis/revalidation_2026-08/scripts/teb_rebuild_and_campaignA.sh` and
`teb_run_campaignB.sh` expect it.
